# God / Sandbox Mode

Direct city patches for laboratory experimentation.

## Modules

- `nyc_world/modes/god.py` — `GodMode`, `GodPatch`, festival, road closures

## Controls

| Key | Action |
|-----|--------|
| `` ` `` or Shift+G | Toggle panel |
| 6 / 1 / 0 | Time presets |
| W/D/O/S | Weather |
| V | Spawn festival |
| C / X | Close / clear roads |

Patches log to `EventLog` for replay.
